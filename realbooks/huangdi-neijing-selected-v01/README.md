# 《黄帝内经》精选 v0.1：校音与使用说明

## 内容

本包包含 6 篇：

1. 素问·上古天真论 —— 人应该怎样活
2. 素问·四气调神大论 —— 顺着四季生活
3. 素问·生气通天论 —— 人与天地之气
4. 素问·灵兰秘典论 —— 身体里的“十二官”
5. 灵枢·本神 —— 什么是精、神、魂、魄
6. 灵枢·天年 —— 人的一生

## 数据字段

每个 segment 包含：

- `text`：古籍原文（按所列古文之家页面底本整理）
- `pinyin_tone_marks`：声调符号拼音，适合 Reader 展示
- `pinyin_numeric`：数字声调拼音，适合程序处理
- `tokens`：逐字符参考拼音；标点的拼音为 null
- `translation`：本数据包重新整理的现代汉语释义

## 拼音来源与边界

古文之家明确提供人工核对的拼音页。本包没有复制其网页排版，而是：

1. 以相应拼音页核对高风险词和古音/多音字；
2. 其余普通字由 ICU `Han-Latin` 生成参考音；
3. 对重要医古文词做了 phrase-level override；
4. 最终出版前仍建议放入 AncientMedicalTTS 再跑一次 Analyzer + 人工确认。

已特别校对/覆盖的例子包括：`被发 pī fà`、`痎疟 jiē nüè`、`飧泄 sūn xiè`、`使气亟夺 qì`、`数犯 shuò`、`緛短 ruǎn duǎn`、`喘喝 chuǎn hè`、`燔炭 fán tàn`、`汩汩 gǔ gǔ`、`皶 zhā`、`穴俞 xué shù`、`膻中 dàn zhōng`、`数中风寒 shuò zhòng fēng hán` 等。

仍建议重点人工复核生僻字、通假字、异体字及不同底本存在差异的词。例如《生气通天论》中的 `菀`、`皶`、`緛`，《本神》中的 `䐃`、`臓`、`俛` 等。

## 译文说明

`translation` 是为普通读者阅读产品重新写的“现代汉语解释”，目标是帮助理解句意，不作为专业医学诊疗说明，也不直接复制古文之家站内译文。

## 推荐工作流

`本数据包 → AncientMedicalTTS 导入/校音 → 腾讯 TTS → Publication Bundle → ancient-medical-reader`

其中 `import/huangdi_neijing_selected_plaintext.txt` 可作为纯文本导入基线；章节 JSON 更适合后续保留拼音、解释等结构化内容。
