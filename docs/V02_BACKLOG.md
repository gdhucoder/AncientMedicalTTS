# v0.2 备选清单

以下内容只记录方向，不属于 v0.1.0 已实现功能：

- Windows 10/11 与 macOS Intel 的正式打包、签名、安装和干净环境验收自动化。
- 更完整的应用数据备份/恢复界面和迁移失败恢复向导。
- 导出时可配置的句间停顿与更细的音频质量检查。
- 更丰富的篇章导入格式、OCR 和大文档工作流。
- 音频质检、字幕/时间轴和更丰富的导出格式。
- 规则/Gold 评测工具的可视化报告与人工复核工作流。
- 不改变默认 TTS 语义前提下的更多语音供应商评估。

本清单不构成当前版本承诺。任何条目进入开发前，都应先单独定义数据迁移、跨平台和隐私边界。
