# v0.1.0 Feature Freeze

冻结日期：2026-09-25  
候选版本：`0.1.0-rc1`

## 冻结范围

v0.1.0 只包含当前已经实现并经过测试的本地古籍朗读工作流：UTF-8 TXT 导入、篇章与段落、发音分析、人工校音、发音规则、注音显示、段落编辑、腾讯云 TTS、单段与全文语音生成、WAV/MP3 导出、用量统计和应用内运行状态。

## 冻结规则

- 不再增加新的阅读、发音分析、规则、TTS、音频导出或云服务功能。
- 允许修复 P0/P1 错误、数据安全问题、跨平台打包问题、明显的 UI 阻塞和文档/测试缺口。
- 允许修正不改变业务语义的文案、布局和无障碍问题。
- Gold 词典、context rules 和 M9 分析器结果在发布收尾阶段不再调参；如发现问题，先记录为已知限制或后续 backlog。
- 任何功能扩展进入 `docs/V02_BACKLOG.md`，不得混入 RC1。

## 发布基线

源码候选版本使用 `0.1.0-rc1`。Python Worker、分析器和第三方组件保持各自版本号，不与桌面应用版本强行同步。发布材料必须写清实际测试平台，不得用构建成功代替真机运行验证。
